# フロントガラス雨粒シェーダーと動的ワイパー払拭・風圧シミュレーション

## 概要

運転席コックピット視点およびチェイス視点でのリアルな雨天ドライブ体験を実現するため、実寸メートル座標系（`1.48m × 0.965m`）上で 3D ワイパーブレードと 1:1 同期するプロシージャル GLSL フロントガラス雨粒・ワイパー払拭シェーダーを実装した。

## 過去に発生した不具合と根本原因の訂正

初期実装では「3D ワイパーの向きや位置が不自然」「雨粒が不自然でワイパーで拭けていない」という問題が発生していた。調査・計測により特定した 5 つの根本原因と解決策は以下の通り：

1. **glTF 2.0 仕様の V 座標反転による上下逆転**:
   - Blender で `v = (z - min_z) / range_z` として出力した UV が、glTF エクスポータの `1.0 - v` 変換によって Three.js 読み込み時に `vUv.y = 0.0` が上端ルーフ側、`vUv.y = 1.0` が下端カウル側に反転していた。そのためシェーダーのワイパー支点がルーフ上端に配置され、雨粒の落下方向も逆転していた。
   - **対策**: `CarModel.normalizeWindshieldGeometryUVs()` および `generate_vehicle_model.py` の双方で、運転席右端 (`x = +0.74`) を `u = 0.0`、助手席左端 (`x = -0.74`) を `u = 1.0`、下端カウル (`y = 0.88`) を `v = 0.0`、上端ルーフ (`y = 1.42`) を `v = 1.0` に厳密正規化した。
2. **3D ワイパーメッシュとシェーダー払拭領域の座標・傾斜角不一致**:
   - 旧 3D ワイパーは傾斜角 `-0.68 rad`（実際のガラス面は `-0.977 rad = -56.0°`）でガラス前方の空中に浮き、初期角度 `rotation.z = 0.2` でガラス中央に縦に突っ立っていた。
   - **対策**: 3D ワイパーをガラス傾斜角 `-0.977 rad` に密着させ、ローカル `-X` 方向へテーパーアーム・センタークリップ・エアロフラットブレード・ラバーリップを構築。ピボット位置（運転席 `(0.46, 0.892, 1.312)` = シェーダー `(0.28m, 0.02m)`、助手席 `(-0.06, 0.892, 1.335)` = シェーダー `(0.80m, 0.02m)`）とブレード払拭半径（運転席 `[0.11m, 0.72m]`、助手席 `[0.11m, 0.63m]`）、掃引角度（下端パーク `0.09 rad` 〜 最大角 `1.68 rad` / `1.58 rad`）を 3D メッシュと GLSL シェーダーで完全一致させた。
3. **ワイパー通過履歴 (`strokeAge`) の欠如**:
   - 旧シェーダーは現在角度の前後 `0.18 rad` のみをクリアしていたため、ブレードが通り過ぎた瞬間に雨粒が 100% 再出現していた。
   - **対策**: 往復ストローク方向 `uWiperDir` (`+1.0`: 往路 / `-1.0`: 復路) と現在角度から、各ピクセルがブレード通過後にどれだけ経過したか (`strokeAge`) を算出し、通過直後は 100% 消去、時間経過とともに新しい雨滴が1粒ずつランダムに着水・成長する物理サイクルを実装した。
4. **水滴計算関数の `effectiveRain` 未連動**:
   - 旧 `calculateStaticMist` は二値判定のみ、旧 `calculateSlidingDrops` は `effectiveRain` を引数にすら取っておらず、ワイパー払拭係数が水滴の消去に反映されていなかった。
   - **対策**: 両関数に局所残存雨量 `effectiveRain` を渡し、各セルのランダム着水閾値 `spawnOrder < effectiveRain` を満たした水滴のみが生成・成長し、ワイパー通過時に `effectiveRain = 0` となると即座に拭き取られるようにした。
5. **ガラス全面の一様な白濁**:
   - 旧シェーダーはガラス全面のアルファに `effectiveRain * 0.38` を加算していたため、水滴がない部分まで白く濁っていた。
   - **対策**: 水滴以外の素ガラス面はクリアなフレネル透過 (`alpha = 0.04..0.22`) に保ち、払拭域外の未払拭エリアのみ微細な結露ミストを与え、水滴内部は球冠（Spherical Cap）法線による上下反転レンズ屈折・メニスカス暗縁・ピンポイントハイライトで描画するよう刷新した。
