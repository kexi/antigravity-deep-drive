# 渋谷・丸の内エリアの街中周回グリッド道路網・交差点開口分割・PLATEAU沿道街区の構築

## 背景と解決した課題

従来のマップ構成では、幹線道路（明治通り `x = -750`、行幸通り `x = 0`、日比谷通り `z = 250` 等）が単一の長大な直線または曲線セグメントとして生成されていたため、以下の問題が存在していた。

1. **交差点における縁石・ガードレール閉塞**:
   `RoadSystem.createStraightRoadSegment()` は道路セグメントの両側に連続した縁石（高さ `0.15m`）とガードレール物理コライダーを生成する。そのため、幹線道路を分割せずに直交する街路を接続すると、交差点の中央を幹線道路側の縁石・ガードレールが横断してしまい、街中へ右左折進入できなかった。
2. **渋谷川護岸パラペット壁による東西分断**:
   渋谷ストリーム東側を流れる渋谷川（`x = -727.5, z = -195 .. -55`）の護岸パラペット壁が連続した1本の壁コライダーとして生成されていたため、稲荷橋通り（`z = -95`）を東西に横断する際に橋の上で車両が衝突していた。
3. **カーナビ道路網と3D物理道路網の乖離**:
   カーナビ画面（`NAVIGATION_ROAD_CORRIDORS`）に描画されている街路（丸の内西通り `x = -156`、丸の内東通り `x = +156`、渋谷桜丘・金王坂周辺の区道）が3D空間側で完全開通しておらず、街中を自由に周回ドライブできなかった。

## 設計と実装（How）

### 1. 渋谷エリアの街中グリッド道路網と12交差点フラットパッド開通

[`apps/web/src/city/tokyoStationMap.ts`](../apps/web/src/city/tokyoStationMap.ts) の `buildShibuyaStreamArea()` において、渋谷駅周辺（`x ∈ [-855, -645], z ∈ [-200, +195]`）を3列×4行の完全な都市グリッド道路網として再構築した。

- **南北軸（3路線）**:
  - **渋谷西口・桜丘ウエスト通り (`x = -855`)**: 並木橋西 (`z = -200`) 〜 桜丘西口 (`z = -95`) 〜 渋谷フクラス西 (`z = +95`) 〜 宮下公園西 (`z = +195`) を結ぶ3区間＋桜丘ループ線。
  - **明治通り (`x = -750`)**: 並木橋 (`z = -200`)・稲荷橋 (`z = -95`)・渋谷駅東口 (`z = +95`)・宮下公園 (`z = +195`) の4交差点で3区間（`z = -188 .. -107`, `z = -83 .. +80`, `z = +110 .. +183`）に分割し、北端は原宿方面カーブ、南端は恵比寿方面カーブへ滑らかに接続。
  - **金王坂・渋谷三丁目イースト通り (`x = -645`)**: 並木橋東 (`z = -200`) 〜 渋谷ストリーム東 (`z = -95`) 〜 金王坂上 (`z = +95`) 〜 宮下公園東 (`z = +195`) を結ぶ3区間。
- **東西軸（4路線）**:
  - **並木橋・八幡通り連絡路 (`z = -200`)**: `x = -855 .. -750 .. -645` の2区間。
  - **稲荷橋通り・サクラステージ南通り (`z = -95`)**: `x = -855 .. -750 .. -645` の2区間。渋谷ストリームと渋谷三丁目イーストビルの間を抜けて渋谷川を横断する。
  - **国道246号・玉川通り・青山通り (`z = +95`)**: `x = -855 .. -750 .. -645` の渋谷街中2区間から東側の青山通りS字カーブ（`x = -632 .. -283`）を経て大手町・丸の内へ直結。
  - **宮下公園・美竹通り連絡路 (`z = +195`)**: `x = -855 .. -750 .. -645` の2区間。
- **渋谷川・稲荷橋の橋梁開口化**:
  渋谷川の護岸壁コライダーを稲荷橋通り（`z = -95`、開口幅 `z = -107 .. -83`）の北側（`z = -83 .. -55`）と南側（`z = -195 .. -107`）に2分割し、橋の上を引っかかりなく東西通行できるようにした。

### 2. 丸の内エリアの東西6区間分割と丸の内西通り・東通り（大名小路）開通

[`apps/web/src/city/tokyoStationMap.ts`](../apps/web/src/city/tokyoStationMap.ts) の `buildRoads()` において、丸の内中央通り (`z = 5`)・丸の内仲通り (`z = 165`)・日比谷通り (`z = 250`) を `x ∈ {-268, -156, 0, +156, +270}` の5交差点で各6区間に分割し、南北街路として **丸の内西通り (`x = -156`)** と **丸の内東通り・大名小路 (`x = +156`)** を開通させた。
また、[`apps/web/src/openData/gsiPlateauLoader.ts`](../apps/web/src/openData/gsiPlateauLoader.ts) の `getPlateauBuildingsForMap()` で東京銀行協会ビル (`13101-bldg-2033`)・丸の内オアゾ (`13101-bldg-4002`)・丸の内永楽ビル (`13101-bldg-1824`)・日本工業倶楽部会館 (`13101-bldg-1336`) の幅員クリアランスを整序し、全道路コリドーとビルの非干渉を保証した。

### 3. 青山通り沿道・渋谷南街区の PLATEAU ビル拡充と多言語対応

国道246号（青山通り）および渋谷並木橋周辺をドライブする際の都市景観密度を高めるため、[`apps/web/src/openData/gsiPlateauLoader.ts`](../apps/web/src/openData/gsiPlateauLoader.ts) に以下の5棟を追加し、[`apps/web/src/core/i18n.ts`](../apps/web/src/core/i18n.ts) の日・英・中ローカライズ辞書へ統合した。

- `13113-bldg-meiji-dori-south-west`: 渋谷並木橋ウエストビル (桜丘南街区)
- `13113-bldg-aoyama-oval`: 青山オーバルビル (国道246号・表参道街区)
- `13113-bldg-shibuya-first-tower`: 渋谷ファーストタワー (金王坂・青山通り南街区)
- `13103-bldg-aoyama-twins`: 新青山ビル (青山ツイン・国道246号沿道)
- `13103-bldg-akasaka-intercity`: 青山通りアベニュータワー (赤坂・表参道街区)
