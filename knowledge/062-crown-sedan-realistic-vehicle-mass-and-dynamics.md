# トヨタ クラウン セダン (AZSH32, 1,980 kg FR) 実車質量・重心・慣性モーメント・荷重移動物理オーバーホール

## 1. 従来実装の構造的課題

[`apps/web/src/physics/vehicle.ts`](../apps/web/src/physics/vehicle.ts) の旧実装には、車両の「重さ・重量感」を損なう 6 つの物理的乖離が存在した。

1. **車重・重心・慣性テンソル不足**: 質量が `1,450 kg` 固定（実車クラウン セダン HEV Z は `1,920 kg`、乗員込み約 `1,980 kg`）で、均質直方体コライダー自動計算任せのため前後重量配分・低重心・ピッチ/ヨー/ロール慣性比が再現されていなかった。
2. **4 輪トルク配分の 2 倍計上バグ**: `maxEngineForce = 6800` に対し 4 輪ループで各輪ごとに `0.42` / `0.58` を乗算していたため合計係数が `2.0` (`13,600 N ≈ 0.96 G`) となり、スーパーカー並みの無重力加速になっていた（また実車の FR ではなく AWD 扱い）。
3. **過剰ダンピングによる荷重移動の平坦化**: `AngularDamping = 4.8`・硬めのサス (`stiffness = 38.0`)・強い姿勢平滑化 (`slerp`) により、ノーズダイブ・スクワット・ロールといった約 2 トン車体の荷重移動が潰されていた。また左右輪連動スタビライザーも未実装だった。
4. **物理的走行抵抗・変速比の欠如**: 空気抵抗 $\frac{1}{2}\rho C_d A v^2$・質量比例転がり抵抗 $C_{rr} m g$・実車ギア比トルクが無く、定数 `LinearDamping = 0.22` と線形出力低下のみだった。
5. **AutoHold による鉛直反力の奪取**: 旧 AutoHold が `updateVehicle()` 直後かつ `world.step()` 直前に `postStepVel.y` を `0` へ減衰していたため、静的平衡時に重力 (`-g*dt`) と相殺する予定のサスペンション反力速度 `+g*dt` を毎ステップ約 14% 奪い、接地荷重が実重量より過大（約 `22,100 N`）に歪んでいた。
6. **タイヤ寸法・サス基準長のズレ**: 物理・ホイール回転計算のタイヤ半径が `0.38 m`、ホイール基準長が自由長 `0.32 m` だったため、`car.glb` の実寸 20 インチタイヤ (`R = 0.34 m`, `x = ±0.86 m`, `z = ±1.39 m`) および静的平衡時車高と乖離していた。

## 2. 設計と実装（`CROWN_SEDAN_PHYSICS_SPEC` SSOT）

- **質量・52:48 重心・3 軸慣性テンソル**:
  - コライダー質量を `0` とし、`rigidBody.setAdditionalMassProperties(1980, (0, -0.08, +0.0556), (3450, 3850, 780), (0, 0, 0, 1), true)` ＋ `recomputeMassPropertiesFromColliders()` で厳密指定。
  - Rapier 内部で主軸慣性は昇順ソート＋ `principalInertiaLocalFrame` 回転として格納されるが、ローカル X/Y/Z 軸へ単位トルクインパルスを加えて実測すると正確に `I_x = 3450` (ピッチ), `I_y = 3850` (ヨー), `I_z = 780 kg·m^2` (ロール) として機能することをテストで検証済み。
- **前後バランス調整サス & アンチロールバー & AutoHold 鉛直保全**:
  - 前後サス剛性 `22.0 / 20.3`、圧側減衰 `2.9 / 2.7`、伸側減衰 `4.1 / 3.8`、`maxSuspensionForce = 28,000 N` により、52:48 重量配分のまま 4 輪すべてが平衡長 `0.2622 m`（車高 `pos.y ≈ 0.6222 m`、静的ピッチ `0.00°`）に水平静止する。
  - 左右輪ストローク差に比例するアンチロールバー（前 `12,000 N/m` / 後 `8,000 N/m`）を車体前後軸周りに適用し、ピッチ荷重移動を阻害せずコーナリングロールを制御。
  - AutoHold では水平速度 (`vx = 0, vz = 0`) と角速度のみ減衰し `postStepVel.y` を改変しないことで、渋谷 3D 傾斜路面 (`dt = 1/30`) の停車無振動（`Δy < 1mm`, `Δpitch/roll < 0.05°`）と厳密な静的荷重平衡 (`ΣF = 19,424 N`) を両立。
- **FR マルチステージハイブリッド駆動・6 段変速・前後ブレーキ配分・走行抵抗**:
  - 後輪左右へ `rearAxleForceN * 0.5` ずつ配分（前輪 `0`、合計 `1.0×`）。2.5L エンジン＋ MG2 電動モーター曲線、6 段ステップギア比 (`D 1`〜`D 6`)、166 kW 駆動輪出力上限、9,200 N トラクション上限、180 km/h リミッターにより、0–100 km/h 約 `7.5 s` の重厚な加速を実現。
  - 空気抵抗 ($C_d = 0.28, A = 2.38\text{ m}^2$)、質量比例転がり抵抗 ($C_{rr} = 0.012 / 0.015 / 0.022$)、速度二乗ダウンフォース ($C_L = 0.08$)、前後 68:32 ブレーキ配分（乾燥 100→0 km/h 約 `38 m`、水たまりはさらに延長）を物理適用。
- **車両モデル・メーター連動 ([`carModel.ts`](../apps/web/src/vehicle/carModel.ts))**:
  - ホイール回転半径を `0.34 m`、上下ストローク基準を `equilibriumSuspensionLength (0.2622 m)` に統一し、12.3 インチメーターの G センサーボールを物理実測 `longitudinalG` / `lateralG` 連動へ刷新。
