# Blender MCP トヨタ クラウン セダン (AZSH32) Class-A 曲面オーバーホール

## 1. ベースライン (`v0`) 360度監査で判明した構造的課題

1. **ボディシェルによるタイヤ・ホイール貫通とホイールハウス地面突き抜け**:
   - 従来の 14 断面長手ロフト (`build_lofted_lower_body`) には真の半円アーチ開口がなく、前後フェンダーの弦三角形がタイヤ上部およびアルミホイールリムへ直接めり込んでいた。
   - 遮光ライナー用円柱 (`center.z = 0.35, radius = 0.365`) の底面が `Z = -0.015m` まで地面下へ突き抜け、タイヤ後方から黒い円筒が露出していた。
2. **平板キャップ・低ポリゴンウェッジ造形と Three.js 光源との乖離**:
   - フロントノーズが `Z = 0.46m` まで低く垂れ下がり（Three.js ヘッドライト光源 `Y = 0.675m`・ウインカーと約 `15cm` 乖離）、前後端が平面キャップ (`f_front` / `f_rear`)・箱型ブロック貼付け構造だった。
   - ナンバープレートは緑色の直方体 7 個で擬似描画されていた。
3. **グリーンハウス造形・内装干渉・Three.js クローム色統合**:
   - 短く角張ったルーフと浮いた円柱状 C ピラー、直方体シート、さらに内装ドア内張り (`Y = -1.09m`) が前輪ホイールハウス内へ露出していた。
   - `carModel.ts` で外装 `Chrome` が `WheelAlloy` と同じ暗いスレートグレー (`0x323a46`) に統合され、切削ホイール・窓モール・エンブレムの金属コントラストが失われていた。

## 2. 設計・モデリング刷新の要点 ([`blender/scripts/generate_vehicle_model.py`](../blender/scripts/generate_vehicle_model.py))

- **共通パラメトリック曲面式 (SSOT) と Class-A 頂点溶着**:
  - `eval_side_x(y, z)`・`eval_front_bumper_pt(u, vz)`・`eval_rear_bumper_pt(u, vz)` を単一の曲面式とし、前後バンパー・前後フェンダー・左右ドア・ボンネットフード・トランクデッキの境界分割数 (`N_SIDE_Z = 12`, `N_BUMPER_U = 32`) を 1:1 一致させたうえで `bmesh.ops.remove_doubles(..., dist=0.0025)` で溶着。隙間・段差・陰影折れを根絶した。
- **極座標トポロジーによる真の半円ホイールアーチ開口**:
  - 4 輪中心 (`wy = ±1.39m, z = 0.340m, R_tire = 0.340m`) 周囲に半径 `R_arch = 0.392m` の 40 分割極座標アーチ開口・立体フェンダーフレア (`R = 0.432m`)・全頂点 `Z >= 0.178m` 厳密保証の遮光ライナーを構築。
- **ハンマーヘッド 4 眼 LED & リア横一文字 LED & トヨタ 3 楕円・正方向 `C R O W N`**:
  - 実車通りの FR セダン車高 (`Z = 0.675..0.720m` フロントブロウ、`Z = 0.875..0.905m` リア一文字テール) へ引き上げ、Three.js 光源・ウインカー座標と 1mm 精度で整合。
  - フロント 4 眼 Bi-Beam LED プロジェクターは曲面有限差分接線から正確な法線・ヨー角 (`atan2(tang.y, tang.x)`) を算出し、全 4 眼ワイドレンズを正面発光させた。
  - 純 Python ベクターストローク描画で 512×256 アンチエイリアス日本ナンバー画像（「品川 330 / さ 16-32」）を生成して GLB へ pack し、前後それぞれ正読方向の UV でマッピングした。
- **6 ライトファストバック・20 インチ 20 本マルチスポーク・面取り RHD 内装**:
  - 16×14 ドームルーフ下にピラーを完全収容し、一体曲面 C ピラーセイル・連続クロームモール・48 分割 4 溝タイヤ・5 穴ラグナット・曲面モノブロックキャリパー・面取り本革シート＆ダッシュボードを造形。
  - 内装ドアパネルを `Y ∈ [-0.88, +0.92]` へ収容し、ホイールハウスへの干渉を完全根絶。

## 3. 360度収束レビュー（v1 → v4）と Three.js 実画面検証での発見・修正

| ラウンド | 検出された課題 | 対処内容 |
| :--- | :--- | :--- |

| **v2 → v3** | ヘッドランプ凹み面への銀塗装滲み、リアロア黒バランスのコーナー矩形カット、リアトヨタエンブレム形状簡素化、A ピラー上端の微小段差 | `N_SIDE_Z = 12` 化・ヘッドランプ光学パネル `+0.015m` クリアランス、先細り独立リアディフューザー成型、3 楕円トヨタエンブレム造形、A ピラー〜カントレール連続フィレット化 |

## 4. Three.js PBR 質感調整 ([`apps/web/src/vehicle/carModel.ts`](../apps/web/src/vehicle/carModel.ts))

- `BodyPaint` をプレシャスメタル (1L5) 本来の明度 (`0x9aa4b4`, `metalness: 0.78`, `roughness: 0.20`) へ調整し、`Chrome`（高光沢サテンクローム `0xcfd8e6`, 自己発光ゼロ）と `WheelAlloy`（ダークチタン `0x3e4756`）を分離することで、実ゲーム画面でも 2 トーン 20 インチホイール・6 ライトクロームモール・エンブレムの立体感が鮮明に描画されるようにした。
- 最終出力: `apps/web/public/models/car.glb`（`1,703,820 bytes` / `69,626 triangles`、3 系統ミラー法線 `+Y` 厳密保証、`Chassis.bounds.z = [0.160, 1.487]`）。
